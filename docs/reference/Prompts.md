# Prompts

`SOMDB.Prompts.json` holds extractor prompts for model `gpt-oss:20b` and remains the unit-test fixture. `items` reads one look reply and returns each four-space object the player can interact with. Each record is `name`, `line`, and `itemType`. The donation pit is `container`. A caller that needs a prompt loads it with `GET /api/v1/agent-prompts/{name}`. The `user` field is a placeholder, not a sample of server text. `look`, `items`, `exits`, and `mobs` use `{look}`. `commands`, `help`, `areas`, `who`, `affects`, and `categories` use a placeholder of the same name. `score` uses `{score}`. `Prompt.for_text(server_text)` puts the live server text in that field. A stored sample is not sent. When login prints the room, `bootstrap()` sends that look reply as the user text of `look`, `items`, `exits`, and `mobs`. `score` asks for one or more intent tokens, such as `expToLevel` or `armorClass`. `Prompt.tokenize(score_text, *intents)` replaces `{intent}`, `{response}`, and `{score}` and narrows `jsonSchema` to those facts.

`PromptSubmission.to_request()` is the body for som-nlp-service `POST /ollama/completions`: `model`, `system`, `user`, and `jsonSchema`. A blank user is rejected with the service message and is not sent. `OllamaClient.complete` returns the `text` field. When the request included a schema, `read_completion` parses that text as JSON. `resources/agent.yml` `ollama.base_url` is `http://localhost:9081`.
