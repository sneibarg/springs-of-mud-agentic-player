# Prompts

`SOMDB.Prompts.json` holds extractor prompts for model `gpt-oss:20b` and remains the unit-test fixture. `items` reads one look reply and returns each four-space object the player can interact with. Each record is `name`, `line`, and `itemType`. The donation pit is `container`. A caller that needs a prompt loads it with `GET /api/v1/agent-prompts/{name}`. The `user` field is a placeholder, not a sample of server text. `look`, `items`, `exits`, and `mobs` use `{look}`. `commands`, `help`, `areas`, `who`, `affects`, and `categories` use a placeholder of the same name. `score` uses `{score}`. `Prompt.for_text(server_text)` puts the live server text in that field. A stored sample is not sent. When login prints the room, `bootstrap()` sends that look reply as the user text of `look`, `items`, `exits`, and `mobs`.

`look_item`, `look_player`, `look_mobile`, and `look_direction` read the reply to `look <item>`, `look <player>`, `look <mobile>`, and `look <direction>`. Their user fields are `{item}`, `{player}`, `{mobile}`, and `{direction}`. `look_item` returns `found`, `result`, `name`, and `description`. `result` is `shown`, `nothing_special`, `ambiguous`, `missing`, or `blocked`. `look_player` and `look_mobile` return `found`, `name`, `description`, `condition`, `equipment`, and `inventory`. `condition` follows the server sentence, from `excellent` through `bleeding`. Equipment `slot` is the worn location, such as `wielded` or `finger`. `inventory` lists the lines after `You peek at the inventory:` and is empty when that block is absent. `look_direction` returns `found`, `door`, `keyword`, and `description`. `door` is `none`, `open`, or `closed`. `The gate is closed.` keeps the keyword `gate`. `Nothing special there.` is `found` false. The room prompt `look` still reads the room printout. Its `items` are things the player can examine. A four-space line has `source` `object`. A description sentence such as `There is a sign on the wall.` has `source` `description`, `name` `sign`, and is the target of `look sign`. `signs of` is not an item.

`score` asks for one or more intent tokens, such as `expToLevel` or `armorClass`. `Prompt.tokenize(score_text, *intents)` replaces `{intent}`, `{response}`, and `{score}` and narrows `jsonSchema` to those facts.

`PromptSubmission.to_request()` is the body for som-nlp-service `POST /ollama/completions`: `model`, `system`, `user`, and `jsonSchema`. A blank user is rejected with the service message and is not sent. `OllamaClient.complete` returns the `text` field. When the request included a schema, `read_completion` parses that text as JSON. `resources/agent.yml` `ollama.base_url` is `http://localhost:9081`.
